## How I approach product work

- Start with a customer problem and the behaviour that needs to change.
- Tie the solution to a business metric: conversion, repeat behaviour, revenue, cost, or reliability.
- Make scope, dependencies, edge cases, and instrumentation explicit before delivery.
- Distinguish observed outcomes from hypotheses, targets, and modelled upside.
- Use AI where it improves the workflow, with human approval for sensitive or high-impact actions.
